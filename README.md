Este espacio contiene los archivos y el código correspondientes a la entrega práctica de la asignatura de **Entornos de Desarrollo (DAM)**. El repositorio ha sido estructurado para mantener un control de versiones limpio, garantizando que el historial de *commits* refleje el proceso de trabajo real.

## 📁 Estructura del Proyecto

Los archivos están organizados para separar la configuración principal de los recursos específicos:

* 📂 **'EntregaIDE_IFNS/'**: Contiene los archivos fuente y recursos principales del proyecto.
* 📄 **'EntregaIDE_INS.drawio'**: Archivo de diagrama de clases.
* 💭 **'README.md'**: Archivo de descripción del repositorio.

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Entorno de Desarrollo (IDE):** Eclipse
* **Control de Versiones:** Git & GitHub
* **Lenguajes:** Java y XML para el diagrama de clases.
